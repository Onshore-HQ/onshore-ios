# Onshore SDK for iOS

Secure collect and reveal views for iOS 15+ (SwiftUI and UIKit). The app holds no credentials: your server mints a single-use client token.

## Install

In Xcode, **File → Add Package Dependencies**, and enter `https://github.com/Onshore-HQ/onshore-ios`. Or in `Package.swift`:

```swift
.package(url: "https://github.com/Onshore-HQ/onshore-ios", from: "0.1.0")
```

and add the product `Onshore` to your target.
